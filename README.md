# FRAMEKIT
# A 3D PRINTABLE COMPOSITION GRID FRAME COLLECTION 
A 3D printable collection of composition guide frame. It is designed to help photographers visualize different composition techniques. It can be used as a physical reference tool to help learning photography. It can be used by placing in front of camera or just using it by hands to understand and practice different compositions in photography. It includes multiple frames that features commonly used photographic compositions such as Golden Ratio, Golden Circles, Phi Grid, Star Grid, Golden Spiral, Rule of Thirds, Golden Triangle and many more. It is designed cleanly and precisely.
